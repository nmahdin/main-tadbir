# استاندارد رابط کاربری تدبیر

این سند مرجع پیاده‌سازی کنترل‌ها و اکشن‌های تازه است. مؤلفه‌های مشترک در `frontend/src/components/common/Primitives.tsx` و توکن‌های آن‌ها در `frontend/src/index.css` قرار دارند.

## دکمه‌ها

- مرجع رسمی همهٔ دکمه‌ها، دکمهٔ «ویرایش محتوا» است: `px-3.5 py-2 rounded-xl text-xs font-bold gap-1.5 shadow-2xs transition-colors`.
- این قرارداد یک‌بار در `BUTTON_REFERENCE_CLASS` و توکن‌های `--button-*` تعریف شده است؛ کپی‌کردن دوبارهٔ این رشتهٔ کلاس در صفحه‌ها ممنوع است.
- تمام اکشن‌های متنی باید از `Button` و یکی از variantهای `primary`، `secondary`، `ghost`، `danger`، `success` یا `warning` استفاده کنند. variant فقط رنگ معنایی را عوض می‌کند و ابعاد، تایپوگرافی، شعاع و فاصله را تغییر نمی‌دهد.
- variant خنثی `secondary` دقیقاً سطح سفید، border خاکستری، متن slate و hover بسیار روشنِ دکمهٔ مرجع را دارد؛ آیکن استاندارد آن ۱۶ پیکسل است.
- دکمه آیکنی باید از `IconButton` استفاده کند؛ کنترل آیکنی مربع است، اما همان شعاع، سایه و رفتار focus دکمهٔ مرجع را حفظ می‌کند.
- وضعیت بارگذاری فقط با ویژگی `loading` روی `Button` نمایش داده شود. افزودن spinner دوم داخل فرزند دکمه ممنوع است.
- اکشن اصلی هر فرم `primary` و اکشن انصراف `secondary` است. دکمه اصلی و فرعی یک فرم باید ابعاد و شعاع یکسان داشته باشند.

## کنترل‌های فرم

- ابعاد مرجع، کنترل‌های مودال ایجاد پروژه است: ارتفاع ۴۰ پیکسل، شعاع ۱۲ پیکسل، padding افقی ۱۲ پیکسل و فونت ۱۲ تا ۱۴ پیکسل.
- از `Input`، `Select`، `Textarea` و `PersianDatePicker` استفاده شود. تاریخ‌گزین همان ارتفاع و شعاع کنترل‌های دیگر را دارد.
- popup تاریخ باید نسبت به کنترل محرک لنگر شود. در containerهای معمول از حالت درجا و فقط در صورت احتمال clipping از portal موقعیت‌یابی‌شده استفاده شود.
- label بالای کنترل، راست‌چین، با وزن bold و فاصله ۶ پیکسل است.
- همه فیلدهایی که submit بدون آن‌ها معتبر نیست با `*` دیداری و `required`/اعتبارسنجی متناظر مشخص می‌شوند. فیلد اختیاری نباید ستاره داشته باشد.
- خطای فیلد کنار همان کنترل و خطای عمومی فرم بالای نوار اکشن نمایش داده می‌شود.
- footer مودال‌های بلند ثابت است؛ فقط بدنه فرم scroll می‌شود تا ذخیره/انصراف همیشه در دسترس بمانند.

## رنگ

- رنگ اکشن و focus اصلی `indigo`، سطوح خنثی `slate`، موفقیت `emerald`، هشدار `amber` و خطا/حذف `rose` است.
- رنگ معنایی فقط برای وضعیت استفاده می‌شود؛ بخش‌هایی مانند وظایف و جدول اطلاعات نباید پالت مستقل سبز/آبی ایجاد کنند.
