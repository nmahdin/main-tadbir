# ADR-0021 — AUTH-EXT-01 final product decisions (AMB-01…AMB-06 resolved)

**Status: ACCEPTED (user authorization, 2026-10-19). Amends SPEC-AUTH-EXT-01 §15.**

| ID | Decision |
|---|---|
| AMB-01 = **B** | **User-chosen usernames remain a user-facing login identifier.** Documented format/length/normalization/uniqueness; normalization-equivalent uniqueness enforced (MariaDB 10.4-safe via a normalized column + unique index); reserved/confusable policy; Persian messages; existing usernames never silently renamed — conflicts under new normalization are reported, and a safe non-destructive migration is proposed instead of auto-renaming. Username+password login stays alongside email/mobile/Google. Unverified contact data is never proof of identity. |
| AMB-02 = **A** | **Personal Free is owned by C5 policy.** Binding limits — Personal Free: 1 personal workspace, 1 member, 3 active projects, 100 MB. Organization Free: 1 organization workspace, 3 members, 5 active projects, 100 MB. AUTH consumes the shared entitlement interface via a configurable plan key; it never hardcodes limits nor creates a fake entitlement. A missing plan/version is a reported dependency; onboarding must not claim success for the entitlement leg in that case. |
| AMB-03 = **A** | **Pluggable `SmsOtpDelivery`.** Provider-neutral contract, fake/test drivers for tests, no production log driver exposing codes, credentials/sender config outside the repo, fail-safe localized `delivery_unavailable` when no verified provider is configured. No vendor is chosen in this package. Raw OTPs/tokens are never logged. |
| AMB-04 = **A** | **Minimal risk step-up:** new device after 30 days of inactivity, plus mandatory reauthentication for sensitive operations (password/identity change, session revocation, destructive actions). Device recognition is a rotating opaque device cookie (hashed at rest), never a sole factor; no IP/geolocation risk engine. |
| AMB-05 = **A** | **14-day deletion grace.** Verified, audited request; during grace, authentication is restricted to deletion-status/cancellation; cancellation does not resurrect revoked sessions; erasure/anonymization after grace subject to ownership/financial/security/legal retention; shared organizational records are never deleted for a member's request; pending date + consequences shown in Persian. |
| AMB-06 = **A** | **Safe legacy-phone transition.** Read-only duplicate/normalization preflight first; new numbers normalized to `+98`; concurrent verification prevented by a database-backed atomic claim (unique verified-phone claim row written in the verify transaction — no SELECT-then-UPDATE race); fail closed; non-destructive duplicate-resolution procedure; durable DB uniqueness only afterwards via a separately verified MariaDB 10.4-safe migration. No overwriting/merging of duplicate accounts. |

Supporting invariants: uniform rate limits on identifier login; enumeration-resistant public responses; audit with redaction; migrations additive and MariaDB 10.4.32-safe; PR #14 stays open/unmerged; independent security scan + ARCH-02 acceptance remain merge prerequisites.
