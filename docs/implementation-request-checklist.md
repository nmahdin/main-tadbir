# درخواست تکمیل سامانه — ۱۴۰۵/۰۷/۰۶

> وضعیت: اجرای بخشی از درخواست، نه نسخهٔ آمادهٔ انتشار کل بسته. روی هاست یا بلهٔ واقعی اعمال/آزمایش نشده است.

## تصمیم‌های تأییدشده
- محتوا: مدیر محتوا یا عضو دپارتمان **یا** تیم مربوطه؛ عضویت، مشاهده/ویرایش را مستقل از مجوز عمومی ویرایش می‌دهد. تأیید/انتشار مجوز جدا دارند.
- جریان هر ایده هنگام ایجاد همان ایده و مستقل از الگوهای جریان محتوا تعریف می‌شود؛ تبدیل ایده به محتوا/تسک عملیات جداگانه است.
- خطای وضعیت بات پس از انتخاب وضعیت جدید گزارش شده؛ علت هاست هنوز بازتولید نشده است.
- کلید سیستمی از UI حذف می‌شود، نه شناسهٔ داخلی و ارتباط رکوردهای موجود.

### اصلاح مرتبط با مجوز تنظیمات
مجوز `workflows.manage` یا `content.manage_process` فقط نوشتن کلیدهای `process_templates` و `workflows` را می‌دهد؛ تنظیمات امنیت/عمومی با این مجوزها باز نمی‌شود. مدیر سیستم و `settings.manage` دسترسی قبلی را حفظ می‌کنند. همگام‌سازی فرانت فقط کلیدهای مجاز را ارسال می‌کند.

## جزئی/نیازمند تکمیل
- [ ] **خطای وضعیت بله روی هاست:** بازیابی انتخاب تکراری و پیام‌های تشخیصی S01/S02/S03 افزوده و آزمون شده‌اند؛ رفع قطعی خطای گزارش‌شده روی هاست اثبات نشده است.
- [ ] **پوشه و دستهٔ جدول‌ها:** فرم ایجاد/ویرایش از رجیستری زندهٔ DAM انتخاب می‌کند و مقدار قدیمی را حفظ می‌کند، اما فیلدهای جدول هنوز برچسب متنی‌اند، نه FK پوشه/دسته. تغییر نام دسته یا پوشه، جدول‌های قدیمی را خودکار مهاجرت نمی‌دهد. مدیریت دستهٔ DAM از صفحهٔ تنظیمات موجود استفاده می‌کند؛ یکپارچه‌سازی سراسری دسته‌ها هنوز انجام نشده.
- [ ] **پایداری پیوست‌ها:** افزودن پیوست جلسه منتظر ذخیره است، اما ویرایش هم‌زمان فرادادهٔ پیوست در چند تب، حذف پیوست و retry مبهم بعد از timeout به مسیر اتمیک/نسخه‌بندی کامل نیاز دارند. فایل آپلودشده ممکن است پس از شکست ثبت فراداده در DAM بماند.
- [ ] **سایر تبدیل‌ها به تسک:** اعلان‌های دوبارهٔ کلاینت با `newTask.id` حذف شده‌اند؛ تبدیل قدیمی ایده/نامه/مصوبه هنوز می‌تواند مرجع موقت تسک را در رکورد مبدأ ذخیره کند. تراکنش جدید فقط تبدیل اقدام جلسه را پوشش می‌دهد. اعلان ساخت مستقیم تسک‌های خودکار `ContentStageTaskSync` نیز باید جداگانه بررسی شود.
